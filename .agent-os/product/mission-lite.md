# Product Mission (Lite)

Flecks Login Animation is a production-ready React component that provides an immersive, animated login/register page experience for the Flecks security client.

The component features a 40-second looping animation with 13 gradient fleck elements, decorative R3 vectors, and a centered logo. Built with React, TypeScript, and Framer Motion, it delivers Figma-perfect visual fidelity with optimized performance for the Flecks development team to drop into their application.
